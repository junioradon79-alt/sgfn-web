# Dossiers partenaires SGNF

**Date de rédaction :** 04 juillet 2026

Ce dossier contient un argumentaire dédié à chacun des 11 profils de partenaires présentés sur la page vitrine `/metiers-partenaires` de `sgfn-web`. Chaque document est pensé pour être envoyé individuellement à un partenaire potentiel de ce métier (collectivité, notaire, banque…), sans exposer le reste du catalogue.

## Principe de rédaction

Chaque dossier distingue explicitement :

- ce qui **fonctionne déjà aujourd'hui, sans compte** (vérification QR publique sur `/verifier`, consultation de la marketplace Mon Terrain) ;
- ce qui existe déjà via un **rôle applicatif réel** de la plateforme (géomètre, opérateur/aménageur, commissaire/vérificateur, chefferie) — provisionnable par invitation ;
- ce qui relèverait d'un **partenariat à construire** (accès de supervision dédié, intégration spécifique) pour les métiers qui n'ont pas encore de rôle applicatif dédié (collectivités, promoteurs, notaires, cabinets juridiques, bureaux d'études, banques, agences immobilières, entreprises de construction, investisseurs).

Aucune information tarifaire n'est incluse sur demande — ces documents restent centrés sur la valeur apportée, la discussion tarifaire venant dans un second temps commercial. Chaque dossier renvoie vers le formulaire de contact préqualifié (`/contact?profil=<slug>`) déjà existant sur le site vitrine.

⚠️ Ces documents sont des supports commerciaux, pas de la documentation technique — voir [docs/](../docs/) pour le dossier de passation développeur.
